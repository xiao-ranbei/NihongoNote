## 一、产品定位

让学习者**不离开原文**就能弄清「这句话是什么、为什么这样说、说话人什么态度、下一句为什么这样接」。
形态：**本机单人 Web 应用**，数据全部落在本机，可长期积累。

## 二、目标与非目标

**目标**
1. 整篇长文的解析可交付、可中断、可续跑、可修正。
2. 成本可控且**可见**：任何付费调用前必须让用户看到预估并明确确认（LLM-011）。
3. 本地能确定的事实（分词、原形、读音、词性、活用、助词用法）绝不问模型。
4. 解析结果必须能回溯到**具体原文位置**，重复词不串位。

**非目标**
- 公网注册/登录/协作/计费；自动抓网页；OCR/PDF；以 Agent 对话替代阅读器；保证模型结论等同教材或教师。

## 三、系统边界与刻意不做

| 在系统内 | 在系统外 |
| --- | --- |
| 分句、分词、形态素、词典与译中、任务编排、校验合并、落盘、成本估算、阅读器交互、修正版本 | LLM（云端 DeepSeek / 本地 Ollama）、浏览器能力、JMDict 数据源 |

**刻意不做**（写下来，避免后续误判为遗漏）：账号与多租户、公网部署、SSR、前端直连 LLM、OCR/图片/PDF、第二套分词权威、把等级混入事实层、前端字符串搜索定位。

## 四、核心用户流程

1. 粘贴日语材料 → 选标题与内容类型（自动识别只作建议）。
2. 保存 → 本地免费预处理（分句、分词、形态素、词典）→ 展示区块与本地覆盖情况。
3. 打开分析工具 → 看到**费用/时长预估**（零 LLM）→ 选档位与模式（完整 / 仅词典）→ 确认后开始。
4. **分析中逐段上屏**（v2 新增），显示已完成/进行中/失败/待处理与累计费用；可随时取消。
5. 在连续阅读框中阅读解析：句子层 + token 层；点句子或词打开解析卡片。
6. 需要时进入「编辑解析」修正字段，AI 原始版本始终可查。
7. 从学习库搜索、按状态筛选、打开历史文章。

## 七、数据模型

```text
Document        id, title, sourceText(不可变), targetLevel(仅解释层偏好), contentType,
                contentTypeSource, status, createdAt, updatedAt
ContentBlock    id, documentId, index, kind, startOffset, endOffset,
                analysisEnabled, detectedType, selectedType            [预留，未启用]
Segment         id = docId:segment:N, documentId, index, text,
                startOffset, endOffset, speaker, status, errorMessage
SegmentAnalysis segmentId, translation, register, grammarSummary, tone, politeness,
                impliedMeaning, replyReason, uncertaintyNote,
                tokens[], schemaVersion, dictionaryCoverage
TokenAnalysis   tokenId = segmentId:token:N, startOffset, endOffset, surface, category,
                lemma, reading, partOfSpeech, conjugation, gloss,
                particleFunction, grammarPoint, explanation, confidence, source
AnnotationRange id, segmentId, start, end, kind, style, targetTokenIds,
                explanation, evidenceTokenIds, confidence, source           [未实现]
AudioAsset      id, segmentId, provider, voice, format, path, speed, prosody   [预留]
```

**不变量**：所有 ID 可推导；所有偏移是相对原文的 UTF-16 偏移；原文保存后不可变；模型只填字段不定义边界；`targetLevel` 不得进入事实层。

## 九、验收与回归

**固定样本**（每次更换模型/提示词/分词器/档位后重跑）：
1. 助词多、活用复杂的普通文章；2. 标题/例句/注释混合的教材材料；3. 委婉拒绝、省略主语的对话；4. 长文分块与取消、中途失败；5. 重复词与同形异义；6. 语气范围与相邻句关系。

**通用检查项**：
- 原文未被改写；token 偏移不串位；解析能指出原文证据；
- 失败可单段重试、进度与费用显示正确；应用重启后仍可读；
- 密钥不出现在浏览器响应与日志中；事件日志不含正文。

**v2 新增检查项**：
- 流式过程中不出现「半截 JSON 上屏」；校验失败的段不进入 `completed`；
- 取消后已完成段不回滚，未完成段可续跑且不重复计费；
- 每次分析只有一个终态事件；`first_segment_ms` / `duration_ms` 可查；
- 词性文本归一后配色与线型稳定；边界不一致时先修复再失败。
