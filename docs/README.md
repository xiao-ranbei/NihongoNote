## 当前结论

第一阶段采用**只在本机运行的 Web 应用**：

1. 在浏览器中粘贴日语文章或对话。
2. 文章按句子展示，词语和句子可悬浮或点击查看 AI 解析。
3. 支持长文本分段分析，并保存文章、解析和跟读录音。
4. 使用云端模型和日语 TTS，API 密钥只保存在本机服务端。
5. Agent/skill 暂不作为主产品形态，后续可作为分析编排、批量处理或浏览器扩展的入口。

本文档基于 2026-08-26 的需求确认结果。供应商价格和模型能力会变化，实施前应重新核对官方定价。
