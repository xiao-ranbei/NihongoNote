## 当前结论

第一阶段采用**只在本机运行的 Web 应用**：

1. 在浏览器中粘贴日语课文、普通文章、新闻/说明文、笔记或对话。
2. 原文在一个连续阅读框中展示：句子色块作为最底层，普通词/助词/功能词/副词使用较浅分类色块，语法色块覆盖对应范围；单层、双层或虚线下划线、波浪线表达词语/助词/功能词/副词/语法/语气，悬浮只高亮范围、点击查看 AI 解析；分句不单独着色。
3. 保存后先在本机完成区块、句段和 token 预处理；深度 AI 分析由用户手动启动，后端按区块和稳定句段分块分析和保存，前端不把文章视觉上拆成卡片，并支持取消后续跑、失败重试和人工修正。
4. 支持同一篇文章中的混合区块；标题/注释默认保留原样，正文/日语例句默认解析。
5. 使用云端 LLM，API 密钥只保存在本机服务端。
6. P1 首先接入 DeepSeek 的 OpenAI-compatible API；Anthropic-compatible API 作为后续可插拔适配器。
7. 学习库可折叠：桌面端为窄侧栏/图标轨道，手机端为抽屉，并支持搜索、内容类型/分析状态筛选。
8. Agent/skill 暂不作为主产品形态，后续可作为分析编排、批量处理或浏览器扩展的入口。

TTS provider 仅预留接口和后续标准朗读/播放方向，当前版本不生成音频，也不包含录音或跟读。

本目录既有产品决策来自 2026-08-26 的需求确认；连续阅读、分层标注、多材料区块和学习库交互于 2026-08-27 进一步澄清。供应商价格和模型能力会变化，实施前应重新核对官方文档和定价。
